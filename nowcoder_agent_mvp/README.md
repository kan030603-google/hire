# 牛客 Agent / AI 应用开发面经 MVP

本目录用于验证牛客面试经验的批量采集、语义筛选与面试题归纳流程。

MVP 口径：

- 类别一：`软件开发 / 人工智能/算法`，按“最新”取 30 篇。
- 类别二：`软件开发 / 后端开发`，按“最新”取 30 篇。
- 不选任何三级标签。
- 关键词仅用于辅助排序，是否纳入由正文语义判断。
- 交付物是去重、归类、合并追问后的题库和参考答案，不是帖子链接列表。

## MVP 结果

- 两个分类首屏各加载 20 条，下拉后均成功加载到 40 条以上，证明无限滚动可批量采集。
- 已保存 60 篇唯一候选帖子，正文批量抓取成功 60/60。
- LLM 语义筛选出 17 篇高相关样本，归并为 40 道主题题目和参考答案。

2026-09-10 的企业筛选在线冒烟还验证了：

- 百度企业选择器与两个二级类别都可正常组合，两类都能从 40 条继续加载到 80 条。
- 抓取 30/30 成功；确定性清洗隔离 2 条窗口外帖子和 1 条明确的他公司误召回，接受集 27 条指纹全部唯一。
- Luna 从 22 篇相关帖子抽取 81 条，Terra 归并为 74 条，Sol 终审交付 71 道题、79 次有效出现，终审通过。

## 文件

- `data/candidates.json`：列表层的 60 篇候选帖子；来源 URL 仅用于溯源、正文抓取和去重。
- `data/posts.jsonl`：60 篇帖子的标准化正文。
- `data/screening.json`：语义筛选口径和纳入样本。
- `scripts/fetch_posts.py`：带重试、限速和断点续抓的正文抓取脚本。
- `scripts/clean_posts.py`：在详情层执行时间窗、明确的他公司标题误召回和内容指纹清洗。
- `output/agent_ai_interview_question_bank.md`：本轮题库与参考答案。

## 续抓

```powershell
python .\scripts\fetch_posts.py
```

脚本会跳过已成功记录，只重试失败项；使用 `--refresh` 可全部重新抓取。

## 2026 年 9 月扩展采集

扩展采集把企业白名单设为源站硬约束，不再先抓所有公司后仅靠文本判断：

1. `config/companies.phase1.json` 保存用户的企业分组，以及经牛客企业选择器核对后的实际选项名。
2. 构建“企业 × 二级类别”采集计划。
3. 每个计划项都必须先在牛客企业选择器中选中对应公司，再下拉采集。
4. 详情页时间窗口限制为 2026-09-01 至 2026-09-30，各查询结果最后按 URL/内容指纹跨类别去重。

```powershell
python .\scripts\build_collection_plan.py
```

已核对的企业才会进入采集计划；未解析企业会被列出但不执行，从而防止误采“全部企业”。由于当前仍在 9 月，现在可回填 9 月 1 日至今的帖子；月末前的新帖需后续增量采集。

仓库 Skill 模式不使用 API Key：主会话编排 Terra、Luna 和 Sol 子代理完成各阶段，用户不需要手动切换模型。
